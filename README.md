# Projek-Akhir-Sistem-Digital-Lanjut
Pengembangan game interaktif Catch It Fast pada FPGA Basys-3 menggunakan VHDL. Proyek ini mencakup perancangan logika permainan (skor, nyawa, FSM, dan LFSR), integrasi VGA Controller untuk grafis 640x480 dengan sistem prioritas pewarnaan, serta kontrol 7-segment display dan tombol perangkat keras.
